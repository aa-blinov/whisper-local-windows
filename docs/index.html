Windows · MIT · Local-first

Press a hotkey, speak, paste.

Lazy to Text records audio on a global keyboard shortcut, transcribes it locally through a Whisper model running in a Docker container, and pastes the result into whatever window has focus. No cloud round-trip, no subscription, no telemetry.

Why local

Audio stays on your machine

Recording, encoding, and Wyoming-protocol RPC all run against localhost:10300. The internet is never involved.

Works offline

After the first model download the app does not need a network connection — useful for trains, planes, and locked-down enterprise laptops.

No usage limits

One-time setup, then transcribe as much as you want. No API keys, quotas, or per-minute billing.

Features

Global hotkey

Ctrl+F2 starts recording, Ctrl+F3 stops and transcribes. Both are remappable in the Shortcuts tab.

Auto-paste

The transcribed text drops into the foreground window via simulated keystrokes. Toggle off if you want clipboard-only behaviour.

Six model presets

Tiny through Large v3, with size, VRAM, speed, and quality metadata shown on each card. Switching the active model reloads the running container automatically.

Searchable history

Every transcription is persisted to logs/transcription_history.json, displayed in a filterable table, and exportable to text.

Hide to tray

The close button minimises to the system tray instead of quitting. Right-click the tray icon for Show / Quit; left-click restores the window.

Single-instance guard

A named-mutex check prevents a second copy from registering the same global hotkeys. The duplicate launch shows a branded warning and exits cleanly.

Live application logs

The Logs tab streams the same log records the file logger writes, so you can see what the recording pipeline is doing in real time.

Settings auto-save

Hotkey edits commit on focus loss, the auto-paste toggle commits instantly. A "Reset to defaults" button restores stock values.

Install

Requires Windows 10/11, Docker Desktop, Python 3.12, and a microphone. 

git clone https://github.com/aa-blinov/lazy-to-text.git
cd lazy-to-text

uv sync                       # creates the venv from uv.lock
docker compose up -d          # local Wyoming faster-whisper backend
uv run lazy-to-text-ui        # launch the app

Press Ctrl+F2 anywhere, speak, press Ctrl+F3. The transcript is pasted into the focused window. The first run downloads the selected model (≈3 GB for large-v3).

System

  • Windows 10 or 11 (64-bit)
  • Microphone (built-in or USB)
  • Docker Desktop ≥ 4.x with WSL2
  • Python 3.12 (only when building from source)

VRAM by model

  • tiny / base — 1 GB
  • small — 2 GB
  • medium — 5 GB
  • large-v2 / large-v3 — 10 GB
